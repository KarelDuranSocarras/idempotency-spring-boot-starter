# idempotency-spring-boot-starter

Spring Boot 3.3.5 starter for idempotent REST endpoints.

## Coordinates

```xml
<dependency>
  <groupId>io.github.<usuario></groupId>
  <artifactId>idempotency-spring-boot-starter</artifactId>
  <version>1.0.0-SNAPSHOT</version>
</dependency>
```
